## 요약

어떤 문제 또는 작업인지, 누구에게 어떤 영향을 주는지 한국어로 설명합니다.

## 확인 수준과 근거

사용자 보고 / 코드 확인 / 실제 재현 / 설계 제안 중 해당하는 수준을 적습니다.
확인한 커밋, 파일·함수, 환경과 관련 이슈를 명시합니다. 추측을 재현 사실로 적지 않습니다.

## 재현 절차 또는 현재 동작

1. 시작 상태와 권한을 설명합니다.
2. 수행한 작업을 적습니다.
3. 실제 결과와 기대 결과를 구분합니다.

## 범위와 제약

API·저장 모델·권한·다국어·공개 읽기 성능·운영 데이터 영향 여부를 적습니다.
미래 버전 계획은 소유자의 착수 지시가 필요하며 이슈 등록만으로 버전을 올리지 않습니다.
비밀번호, 토큰, .env 원문, 개인정보와 비공개 문서 원문을 첨부하지 않습니다.

## 완료 조건

- [ ] 기대 동작과 검증 가능한 기준을 적습니다.
- [ ] 필요한 회귀 테스트와 브라우저·모바일 확인 범위를 적습니다.
- [ ] 변경한 기술 계약과 운영 절차를 관련 문서에 반영합니다.

## 검증 결과

실행한 명령과 결과, 미실행·환경 제약·추가 확인 사항을 구분합니다.
